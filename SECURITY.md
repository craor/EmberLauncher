# Безопасность

Лаунчер качает файлы только по https и только с заранее известного списка адресов: Modrinth, CurseForge CDN, зеркало OptiFine и GitHub Releases.

В репозиторий нельзя класть `server.json`, токены, пароли и личные ссылки. Единственное публичное имя — ник автора `craor`.

Обновление ставится только если файл с GitHub похож на программу этой системы и, когда GitHub отдаёт sha256, сумма сходится.

Ошибку лучше описать в Issues репозитория. Секреты в issue не пиши.
